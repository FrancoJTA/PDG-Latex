## Cómo seguir esta lista

1. Confirmar acceso a texto completo de cada uno (Sci-Hub no, buscar en
   Google Scholar / repositorio institucional / contactar autor).
2. Leer y decidir cuáles realmente aportan (no todos van a servir — la
   búsqueda fue amplia a propósito para no perder cobertura).
3. Los que se confirmen, pasan a `perfil/perfil.bib` en formato APA (ver
   `documento/referencias/norma-analisis.md` §7.1).
4. Ampliar la búsqueda con PaperQA2 (ver `documento/05-herramientas-flujos.md`)
   una vez que haya un primer lote de PDFs descargados.

## Nota sobre la búsqueda

Semantic Scholar devolvió `429 Too Many Requests` en la mayoría de los
intentos (límite sin API key) — la mayor parte de esta lista salió de
CrossRef. OpenAlex, ordenado por citas, devolvió resultados irrelevantes
para búsquedas de texto libre de varias palabras (dominado por papers
masivamente citados de otras áreas) — no se usó para la lista final.
